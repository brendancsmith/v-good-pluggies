## Install

```zsh
# add this marketplace
claude plugin marketplace add brendancsmith/v-good-pluggies

# install a plugin from it
claude plugin install <plugin>@v-good-pluggies
```

Inspect what a plugin ships with `claude plugin details <plugin>`.
